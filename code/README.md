# Command-line scripts

Run the examples from this directory. Start with the
[repository README](../README.md) for installation and the complete 9MEC design
comparison, or the [usage guide](../docs/usage.md) for additional commands.

```sh
python3 show.py matrix results/pathways/queries/3hp
python3 show.py endpoints results/design-walkthrough
```

Use `python3 SCRIPT.py --help` to see each script's arguments.
